# snippets

Text and code pulled into the deck from disk, so swapping in the real thing is a
one-file edit instead of a hunt through `slides.md`.

| File | Used by | Replace with |
|---|---|---|
| `wireshark-capture.txt` | "Sniffing the traffic" | A few lines from your own `btsnoop_hci.log` capture, with the ATT Write highlighted |

Slidev includes these with `<<< @/snippets/<file>`.
